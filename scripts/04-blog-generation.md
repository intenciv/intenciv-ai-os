# SOP 04 – Blog Generation

## Purpose

Create a high-quality, SEO-optimized educational blog that builds trust, improves Google rankings and encourages online bookings.

Every blog should educate first and sell second.

---

# Objective

Generate one original blog based on today's selected topic.

The blog should:

- Improve SEO
- Build trust
- Educate patients
- Promote preventive healthcare
- Support IntenCiv's services

---

# Inputs

Today's Selected Topic

Content Calendar

Knowledge Base

SEO Keywords

Brand Guidelines

Language Rules

Length

Friendly

Educational

Scientific

Easy to understand

# Writing Rules

Never diagnose.

Never prescribe medicines.

Never guarantee treatment outcomes.

Always explain in simple language.

Always recommend consulting a qualified doctor when appropriate.
