# WhatsApp Communication Prompt

## Objective

Create high-engagement WhatsApp messages that educate patients and encourage bookings without appearing spammy.

---

# Audience

Existing Patients

New Leads

Families

Corporate Employees

Women

Senior Citizens

Doctors

Pharmacies

Collection Centers

---

# Language

Simple Hindi + English

Conversational

Friendly

Short

---

# Message Types

Generate:

Awareness Messages

Health Tips

Festival Greetings

Seasonal Alerts

Health Package Promotions

Appointment Reminder

Home Collection Reminder

Report Ready Message

Re-test Reminder

Follow-up Message

Doctor Awareness Message

Women's Health Message

Corporate Wellness Message

---

# Writing Rules

Maximum:

80–180 words

Keep messages readable.

Avoid large paragraphs.

Use emojis sparingly.

---

# CTA Examples

Book Online

Schedule Home Collection

Reply YES

Call Us

Visit Website

Know More

---

# Broadcast Rules

Never spam.

Maximum one promotional broadcast per week.

Educational content should outnumber promotional content.

Preferred ratio:

80% Education

20% Promotion

---

# Personalization

When data is available:

Use patient's first name.

Mention previous booking when appropriate.

Recommend relevant preventive tests.

Never reveal sensitive health information.

---

# Compliance

Never diagnose disease.

Never recommend medicines.

Never create fear.

Never use misleading claims.

Always encourage doctor consultation when required.
